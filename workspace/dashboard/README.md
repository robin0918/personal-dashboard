# 🖥️ 龙王的个人工作台

> 可视化项目管理 + 社媒账号管理 + 自动化运营平台

## ✨ 核心功能

### 📊 项目管理
- 所有项目统一展示
- 实时进度追踪
- 目标设定与完成率

### 🎯 目标管理
- 年度/月度目标设定
- 进度可视化
- 习惯养成追踪

### 📱 社媒账号管理
- 多平台账号绑定（Twitter、YouTube、Instagram 等）
- 独立环境（指纹浏览器级别隔离）
- 数据统计分析

### 🤖 自动化运营
- 配合 Openclaw
- 自动发布内容
- 智能调度任务

## 🛠️ 技术栈

- **前端**: React + TailwindCSS + Recharts
- **后端**: Node.js + Express
- **数据库**: SQLite（本地）/ PostgreSQL
- **认证**: JWT + 多因素认证
- **自动化**: OpenClaw Integration

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/robin0918/personal-dashboard.git
cd personal-dashboard

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 📁 项目结构

```
personal-dashboard/
├── src/
│   ├── components/    # UI 组件
│   ├── pages/        # 页面
│   ├── hooks/        # 自定义 Hooks
│   ├── utils/        # 工具函数
│   ├── store/        # 状态管理
│   └── services/     # API 服务
├── server/           # 后端服务
└── docs/            # 文档
```
