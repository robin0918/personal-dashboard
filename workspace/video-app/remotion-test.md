## 🎬 Remotion 是什么？

Remotion 是一个用于在 **React** 中创建视频的框架，可以：
- 用 React 代码编写视频
- 创建动态图形和动画
- 生成数据可视化视频
- 制作社交媒体内容

## 📚 功能列表

| 分类 | 功能 | 说明 |
|------|------|------|
| 🎨 **基础** | 动画、文字动画 | 基础动画技能 |
| 📊 **图表** | 图表、数据可视化 | 图表和图形模式 |
| 🎵 **音频** | 音频导入、剪辑、音量 | 音频处理 |
| 🎬 **视频** | 视频嵌入、剪辑、速度 | 视频控制 |
| 🖼️ **图片** | 图片导入、动画 | 图片处理 |
| 📝 **字幕** | SRT 字幕、语音转文字 | 字幕功能 |
| 🔄 **转场** | 场景转场效果 | 过渡动画 |
| 📐 **排版** | 字体、文本测量 | 文字排版 |
| 🎭 **3D** | Three.js 集成 | 3D 内容 |
| 📱 **响应式** | 多种尺寸 | 适配不同平台 |

## 🏗️ 项目结构

```
video-app/
├── src/
│   ├── compositions/     # 视频合成
│   ├── components/       # 组件
│   ├── assets/          # 资源文件
│   └── utils/           # 工具函数
├── package.json
└── remotion.config.js   # 配置
```

## 💡 使用示例

```bash
# 创建新项目
npx create-video@latest my-video

# 开发模式（热重载）
npm run dev

# 构建视频
npm run build

# 渲染特定合成
npx remotion render MyVideo
```
